# Digital Visiting Card

A responsive digital visiting card built with **HTML, CSS, and JavaScript**.

The idea is simple: instead of repeatedly printing physical visiting cards, a single digital card can be shared, saved, and accessed through a QR code.

## ✨ Features

- 🔄 Front and back card with flip interaction
- 📱 Responsive design for desktop and mobile
- 📥 Download either side of the card as a PNG
- 📤 Share both card sides using the Web Share API
- 👤 Save contact directly using a vCard
- 📷 QR code access to the live card
- 🔗 Direct contact and website links
- 🎨 Custom themed card design
- ⚡ Fully client-side — no backend required

## 🛠️ Concepts Used

The project was built using vanilla web technologies and browser APIs.

### Frontend
- HTML5
- CSS3
- Responsive design
- CSS `clamp()` and flexible sizing
- CSS 3D transforms for the card flip

### JavaScript
- DOM manipulation
- Event handling
- Dynamic UI interactions
- Canvas API for generating card images
- Blob and File APIs
- Web Share API
- Clipboard API
- vCard generation
- Browser URL/Object URL APIs

### Deployment
- GitHub Pages

## 💡 Why a Digital Visiting Card?

A physical visiting card can be misplaced, damaged, or run out of.

A digital card provides a reusable alternative:

- 📱 **Always accessible** — save it on your phone and open it whenever needed.
- 📷 **Easy to share** — scan a QR code and instantly open the card.
- 🤝 **Easy to share with others** — send the card digitally without needing another physical card.
- 📥 **Downloadable** — save the card directly to your device.
- 👤 **Save contact instantly** — add the contact without manually typing the details.
- 🌱 **Less repeated printing** — update and share the digital card without printing a new batch of cards.
- 🔗 **Everything in one place** — contact details, links, and other information can live on the same card.
